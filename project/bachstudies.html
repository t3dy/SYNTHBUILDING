Bach Studies (scholarship, not music)

STUB  C:\Dev\BachStudies · SQLite, Python (PyMuPDF), vanilla static HTML, GitHub Actions (unused)

BachStudies follows the same DH-framework pattern as several of Ted's scholarly portals: a corpus/ of 13 Bach-scholarship books (Wolff, Stauffer, Leaver, Demeyere's Art of Fugue, Rathey, Forkel, and others) converted from PDF to Markdown, feeding a SQLite database and a static-HTML build. Its CLAUDE.md states clean system invariants (data flows one direction, source to DB to HTML; the DB is the only source of truth) and its own roadmap marks several phases 'READY,' but on inspection those phases ran only shallowly.

The database currently holds 12 primary entities, 12 scholars, 12 bibliography entries, 12 dictionary terms (Fugue, Cantata, Chorale, Counterpoint, Basso continuo, Passion, Thomaskirche, Leipzig, Cothen, Weimar, Bach Revival, Baroque -- all genuinely reviewed and high-confidence), and zero essays. But the committed site/dictionary/ folder contains 13,815 HTML pages, of which all but those 12 are essentially empty stubs left over from an indiscriminate corpus-extraction pass whose output no longer matches the reseeded 12-row database -- a stale, unpruned build sitting in git.

BACHPEDAGOGY.md proposes an ambitious four-tier music-theory curriculum with short public-domain-MIDI audio snippets as illustrative clips -- the only place audio is mentioned anywhere in this project -- but it is entirely unbuilt: no theory_lessons table, no MIDI rendering code, nothing beyond the planning document. The repo has no git remote configured at all, so its GitHub Actions Pages-deploy workflow, though well-formed, has never actually run.

This is a text and research project with no music-composition or audio-production component. It should not be filed alongside the actual music-hacking projects in this catalog, despite sharing Bach's name with Chipped On Bach.

Stuck / next
Prune the ~13,793 junk dictionary stub pages before the site is presentable; the underlying scholarship (12 solid entries) is fine as far as it goes but the roadmap's Phase 3 (AI enrichment) and Phase 7 (human review) were never started.
