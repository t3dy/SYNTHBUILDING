ANTIGRAVFUGIENS

SCRATCH  C:\Dev\EMBLEMSIN3D\ANTIGRAVFUGIENS · Vanilla JS + Web Audio API

ANTIGRAVFUGIENS is a four-file experiment branch (README, app.js, index.html, style.css) sitting inside EMBLEMSIN3D that takes the same 50 fugues and 10 NES game-palettes as the main jukebox and adds a second axis: ten 'studio tricks' per emblem, named for alchemical processes rather than ordinary studio-effect names -- tape delay, mercury vibrato, gated black-fire envelopes, albedo wash, rubedo phasing, ouroboric feedback, projection glitch, and more. Alongside these it offers six deliberately weird interactive toys: the Levitating Athanor, Ouroboric Dub, Dewpoint Runner, Sword/Egg Breakbeat, Rose-Garden Lockstep, and Sublimation Pinball. It only runs from the parent project's local server, isn't linked from the main site navigation, isn't listed in the deploy-state's published-paths, and has never been deployed anywhere.
