STABLE  C:\Dev\arpeggiator-composer · JSFX, ReaScript, Python (core/, reascript/, reaper_projects/)

arpeggiator-composer is a REAPER-targeted deterministic MIDI arpeggiator, structured like a real small software project rather than a one-off script: a core/ logic layer, a jsfx/ folder for the REAPER-side plugin component, a reascript/ folder (REAPER's own Lua/Python API, run inside REAPER), reaper_projects/ for example projects, and a tests/ folder. Unlike the rest of this catalog it isn't NES-specific -- it's general-purpose composition tooling that happens to live in the same REAPER/JSFX ecosystem.
