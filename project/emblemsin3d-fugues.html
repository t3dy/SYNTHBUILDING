Emblems in 3D -- 8-bit Fugue Engine

ACTIVE  C:\Dev\EMBLEMSIN3D · Vanilla JS + Web Audio API, three.js 0.160

▶ live site

EMBLEMSIN3D is a large three.js project turning Michael Maier's Atalanta Fugiens (1617, 51 emblems) into a walkable 3D world rendered in the book's own woodcut style. Its music slice, chiptune.js, is a small Web Audio engine loading pre-transcribed note data per emblem (from EmblemRoguelike's fugues.json: bpm, beats, and per-voice note arrays) and rendering it through an NES-APU emulation -- two pulse-wave channels via PeriodicWave at 50%/25% duty plus a triangle bass, each with per-note ADSR. This is transcribed playback in synthesized 8-bit voices, not generative composition -- the notes are Maier and Merian's actual counterpoint. gamesynths.js supplies ten 'game palettes' mined from 'nsfripper's CODEXSYNTH bench' (Mario, Zelda, Metroid, Castlevania, Contra, Final Fantasy, Kirby, Bubble Bobble, Bionic Commando, Wizards & Warriors), retuning duty cycle, ADSR, vibrato, and gain to evoke each game's voice; every fugue page cycles through all ten as it loops.

Three surfaces use this engine: the Fugue Jukebox (grid of 50 fugues), per-emblem fugue pages (10 cycling versions plus a scholarship accordion pulling Claudiens-DB commentary), and the Great Work cinematic tour (plays each emblem's actual fugue as the camera arrives). As of a later phase the same engine was vendored directly into the walkable world, so standing at a station plays that emblem's canon, off by default behind a mute toggle -- this part is confirmed live.

The standalone jukebox/fugue-page experience never got ported to the GitHub Pages build; it depends on absolute C:\Dev-rooted paths to sibling-project image assets that only resolve on a local dev server, and the project's own deploy-state notes flag this as intentional, not an oversight.

Stuck / next
Local-only status for the standalone jukebox is by design (absolute-path dependency), not a bug to fix casually -- vendoring those assets for Pages would be real work. Folding ANTIGRAVFUGIENS's studio-effect variants into the main jukebox is the more natural next step and hasn't been started.
