Emblems in 3D -- 8-bit Fugue Engine

ACTIVE  C:\Dev\EMBLEMSIN3D · Vanilla JS + Web Audio API, three.js 0.160

▶ live site

EMBLEMSIN3D is a large three.js project turning Michael Maier's Atalanta Fugiens (1617, 51 emblems) into a walkable 3D world rendered in the book's own woodcut style. Its music slice, chiptune.js, is a small Web Audio engine loading pre-transcribed note data per emblem (from EmblemRoguelike's fugues.json: bpm, beats, and per-voice note arrays) and rendering it through an NES-APU emulation -- two pulse-wave channels via PeriodicWave at 50%/25% duty plus a triangle bass, each with per-note ADSR. This is transcribed playback in synthesized 8-bit voices, not generative composition -- the notes are Maier and Merian's actual counterpoint. gamesynths.js supplies ten 'game palettes' mined from 'nsfripper's CODEXSYNTH bench' (Mario, Zelda, Metroid, Castlevania, Contra, Final Fantasy, Kirby, Bubble Bobble, Bionic Commando, Wizards & Warriors), retuning duty cycle, ADSR, vibrato, and gain to evoke each game's voice; every fugue page cycles through all ten as it loops.

Three surfaces use this engine: the Fugue Jukebox (grid of 50 fugues), per-emblem fugue pages (10 cycling versions plus a scholarship accordion pulling Claudiens-DB commentary), and the Great Work cinematic tour (plays each emblem's actual fugue as the camera arrives). As of a later phase the same engine was vendored directly into the walkable world, so standing at a station plays that emblem's canon, off by default behind a mute toggle -- this part is confirmed live.

The standalone jukebox/fugue-page experience never got ported to the GitHub Pages build; it depends on absolute C:\Dev-rooted paths to sibling-project image assets that only resolve on a local dev server, and the project's own deploy-state notes flag this as intentional, not an oversight.

There is a real, small discrepancy in the source material worth stating precisely rather than glossing over: Maier's book itself is illustrated across 51 numbered emblem plates (EMBLEMSIN3D's own README describes "fifty-one emblems on one race course," and its gallery page independently counts "51 Atalanta Fugiens emblem plates"), while the music data specifically -- `fugues.json`, and every reference in `chiptune.js`'s own comments -- consistently says "50 three-voice canons." The most likely and simplest reconciliation, based on both figures being internally consistent within their own domains, is that one plate (conventionally the closing or epilogue-adjacent emblem) was never set as a fugue by Maier in the first place, meaning the correct framing is 51 emblems, 50 of which carry musical settings, rather than treating the two figures as contradictory.

`chiptune.js`'s actual synthesis is a real, Fourier-series-built approximation rather than a simple built-in oscillator type: both pulse channels are constructed via `createPeriodicWave` from a 32-harmonic Fourier square-wave series, with duty cycle as a genuine per-channel, per-palette parameter (not a fixed 50%/25% pair) -- the default palette uses 50% and 25% duty, but each of the ten game palettes sets its own values independently. The triangle channel uses the Web Audio API's native triangle oscillator type directly. Envelopes are linear attack-to-peak, linear decay to a sustain level, held, then an exponential release capped at 40% of the note's total duration; a second low-frequency oscillator modulates pitch detune in cents for vibrato, again with per-channel depth and rate. Voice allocation is pitch-aware: notes at or below MIDI note 52 preferentially claim the triangle channel first, then the two pulse channels, while higher notes reverse that priority -- a deliberate design choice putting bass content on the channel best suited to carry it. A permanently-active master bus applies a 4,400Hz low-pass filter plus a short, subtle delay-feedback loop (160-millisecond delay, 16% feedback, 10% wet) for ambience.

The ten confirmed game palettes carry genuinely distinct, specific parameters rather than cosmetic naming: Metroid uses the narrowest duty cycle of the set (12.5% on both pulse channels) with a pronounced 22-26 cent vibrato at 6.5Hz and the longest release of the ten, evoking its game's spacious, echoing soundtrack; Contra uses the hardest, fastest attack (2 milliseconds) matching its driving action-game pacing; Final Fantasy uses a slower attack (20-30 milliseconds) and the highest sustain level (75-80%) of any palette, closer to an orchestral pad than a percussive game-lead sound; and Wizards & Warriors uses the slowest vibrato rate (4.8Hz) and longest sustain and release of the set. Playback is triggered globally by a keyboard shortcut (pressing M, or a `&sound=1` URL parameter) over the walkable world rather than by proximity to any specific station, and the active game palette advances automatically by one step every time a fugue's loop repeats, not in response to player position -- meaning a player standing at one emblem long enough will hear it cycle through several of the ten palettes in sequence. A documented, non-obvious risk sits in the deployed Pages build specifically: its fugue data and synthesis engine are vendored, static copies checked into the deployment folder rather than live references to the EmblemRoguelike source project, so a future update to the canonical fugue transcriptions would not automatically propagate to the live site without someone remembering to manually re-copy the vendored files.

Stuck / next
Local-only status for the standalone jukebox is by design (absolute-path dependency), not a bug to fix casually -- vendoring those assets for Pages would be real work. Folding ANTIGRAVFUGIENS's studio-effect variants into the main jukebox is the more natural next step and hasn't been started.
