ANTIGRAVFUGIENS

SCRATCH  C:\Dev\EMBLEMSIN3D\ANTIGRAVFUGIENS · Vanilla JS + Web Audio API

ANTIGRAVFUGIENS is a four-file experiment branch (README, app.js, index.html, style.css) sitting inside EMBLEMSIN3D that takes the same 50 fugues and 10 NES game-palettes as the main jukebox and adds a second axis: ten 'studio tricks' per emblem, named for alchemical processes rather than ordinary studio-effect names -- tape delay, mercury vibrato, gated black-fire envelopes, albedo wash, rubedo phasing, ouroboric feedback, projection glitch, and more. Alongside these it offers six deliberately weird interactive toys: the Levitating Athanor, Ouroboric Dub, Dewpoint Runner, Sword/Egg Breakbeat, Rose-Garden Lockstep, and Sublimation Pinball. It only runs from the parent project's local server, isn't linked from the main site navigation, isn't listed in the deploy-state's published-paths, and has never been deployed anywhere.

The ten studio tricks are confirmed by name directly from the project's own README, though the file does not elaborate on each beyond its title: tape delay, mercury vibrato, gated black-fire envelopes, albedo wash, arpeggiated citrinitas harmony, rubedo phasing, ouroboric feedback, square-wave bass, volatile ladder tones, and projection glitch -- each one layered as a second effects axis on top of the same ten NES game palettes the main jukebox uses, meaning the experiment's full combinatorial space is ten fugues times ten palettes times ten effects, though nothing in the project suggests every combination was actually generated or is browsable as such; it reads as a toolkit for exploring that space live rather than a pre-rendered catalog of it.

The six interactive audio toys each carry a one-line mechanic description directly from the README, worth quoting rather than paraphrasing since they're evocative and specific: the Levitating Athanor works because "fugue pressure makes the plate hover; clicking vents heat"; Ouroboric Dub because "feedback draws a self-feeding circular serpent"; the Dewpoint Runner because "vibrato and delay turn the emblem into a moisture field"; the Sword/Egg Breakbeat because "short envelopes and downbeat hits cut the egg"; Rose-Garden Lockstep because "harmonies rotate geometric locks"; and Sublimation Pinball because "notes become charged pellets in a volatile cabinet." These read as genuinely playful, alchemically-literate interaction design -- each toy names a real operation or image from the Atalanta Fugiens/alchemical tradition (athanor furnaces, the ouroboros, sublimation, the philosophical egg) and maps it to an audio-reactive mechanic rather than treating the alchemical theming as pure decoration, which is exactly the standard the workspace's own governing rule for mechanics holds projects to: a player should be able to recover the symbolism from the behavior. Whether that standard is actually met in practice -- whether playing Sublimation Pinball genuinely communicates "sublimation" without being told -- would require actually running the toy rather than reading its one-line description, and was not independently verified in this pass; only four files exist in the whole project (`index.html`, `app.js`, `style.css`, `README.md`), so verifying it directly would be a small, bounded task if anyone wanted to confirm the standard is met before ever considering giving this experiment a real deployment.

Framed against the workspace's broader standard for how symbolic and mechanical design should relate -- a mechanic should let a player recover its meaning from how it behaves, without being told -- this experiment is a genuinely promising candidate to hold up against that bar precisely because its naming is so specific and so clearly drawn from the same alchemical vocabulary (athanor, ouroboros, sublimation, the philosophical egg, black/white/yellow/red stages implied by "albedo wash" and "rubedo phasing") that the source Atalanta Fugiens material itself uses throughout. That specificity is also exactly why it deserves more visibility than it currently has: a project this legible, sitting completely unlinked from any site navigation and undeployed anywhere, is a case where the gap between "built" and "seen by anyone but Ted running a local server" represents lost value rather than an unfinished creative idea still needing work.
