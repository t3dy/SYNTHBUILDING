NSFRIPPER (NES Music Extraction Studio)

ACTIVE  C:\Dev\NSFRIPPER · Python (py65 6502 emulator, numpy, mido), REAPER JSFX, SQLite oracle DB, static site generator

▶ live site

NSFRIPPER builds a full NES-audio pipeline: NSF files run through 6502 CPU emulation (py65), capturing per-frame APU register state at 60Hz, which becomes 4-channel MIDI with CC11 (volume) and CC12 (duty-cycle) automation preserving the original driver's envelope, then REAPER .rpp projects using a custom unified JSFX synth called ReapNES Studio. For flagship games (Castlevania 1, Contra, Wizards & Warriors) it goes further, parsing the actual ROM sound-driver code and validating output frame-by-frame against Mesen-emulator hardware traces -- the project's fidelity hierarchy (Trace > SysEx > NSF emulation > CC automation > ADSR approximation) is a load-bearing rule repeated throughout its 40-rule architecture doc.

A SQLite-backed 'oracle' knowledge base (ANTIRIPPER/antiripper_v2.db) records extraction decisions, prevention patterns, and hardware facts as institutional memory across sessions -- a genuinely mature piece of infrastructure among Ted's projects. The site is live and generated deterministically from output/.

The last commit (2026-04-20) shipped a three-variant architecture specifically so Ted could ear-test and choose: Variant A 'Double Dose' (audio stems + JSFX), Variant B 'Live Wire' (pure JSFX/MIDI, playable live), and Variant C 'Ditto Head' (JSFX-rendered stems, deferred, never built). The README's own roadmap says the next step is simply: listen to A and B, decide whether to keep the Python stems pipeline, go JSFX-only, or build C. That decision was never made and never logged -- no commits since.

A Bach-mashup side project (bach_nes_mashup.py and siblings) pairs J.S. Bach MIDI with NES instrument timbre presets extracted from Castlevania/Contra/Metroid/Gradius stage palettes; see CHIPPEDONBACH.md for the full account, including two finished MP4 preview videos sitting at the C:\Dev root and 117 generated-but-unrendered projects.

Open technical items at last commit: whether the Python DSP fixes (14kHz analog lowpass, DC blocker, bandlimited pulse synthesis) need porting into the live JSFX synth too; a known ~15% non-linear-mix overload from summing independently-rendered stems in REAPER's bus; Metroid's intro track hangs the py65 emulator; a Capcom 6C80 ROM parser (~2 weeks estimated, not started) that would add ~40 games to trusted status; and three unsolved hardware mysteries called out explicitly in its own docs (why Castlevania produces noise drums without the $4015 bit-3 enable the spec requires; why SMB's driver writes a constant DC value to $4011 every frame; region-driver divergence between CV3's US and JP releases).
