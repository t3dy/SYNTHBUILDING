Designing Software Synthesizer Plug-Ins in C++: For RackAFX, VST3, and Audio Units

Designing Software Synthesizer Plug-Ins in C++ is a 912-page, deeply technical, code-driven textbook by Will Pirkle — author of several widely used Focal Press/Routledge audio-DSP programming books and creator of the free RackAFX plugin-prototyping framework used as this book's primary teaching environment, alongside full coverage of exporting the same DSP code to VST3 and Audio Units plugin formats. The book's approach is to build a complete, working polyphonic software synthesizer incrementally in C++, teaching digital synthesis theory and object-oriented plugin architecture simultaneously: rather than treating synthesis theory and software engineering as separate concerns, each chapter pairs a DSP concept with its concrete C++ class implementation. Visible in the extracted cover and page images are direct code excerpts — delay-line difference equations (dLeftDelayIn/dRightDelayIn feedback calculations), and, strikingly, a full C++ class declaration for CMoogLadderFilter : public CFilter, implementing the specific nonlinear four-pole Moog transistor-ladder filter topology by name — indicating the book teaches not generic textbook filters but specific, musically important circuit models translated into code. Based on its scope and Pirkle's other books, chapters cover: audio plugin architecture and the host/plugin API models (RackAFX, VST3, AU); oscillator design (including bandlimited waveform generation to avoid aliasing); envelope generators (ADSR and variants); LFOs and modulation routing; filter design (multiple topologies including the Moog ladder, state-variable, and biquad filters); voice architecture and polyphony/voice-stealing; and effects processing. It is written for programmers with working C++ knowledge who want to build real, shippable synth plugins — it assumes programming competence (classes, inheritance, real-time constraints) that most other books in this library do not, and is unambiguously a professional/serious-hobbyist DSP engineering text rather than a musician's conceptual guide. For SYNTHBUILDER, this is the single most directly relevant technical resource in the entire library: it is a from-scratch, code-level guide to building exactly the kind of synthesizer plugin SYNTHBUILDER's VST3/JUCE phase aims at (per SYNTHBUILDER's own CLAUDE.md, JSFX now, 'eventually VST3/JUCE'), including working, named implementations of core DSP building blocks (oscillators, envelopes, filters including the Moog ladder) that could be ported to JSFX's simpler scripting language or directly adapted for a future VST3/JUCE build.
